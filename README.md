# Genius Racer

Genius Racer is an educational arcade game where players learn multiplication tables by progressing through levels and collecting coins.

## About the project

The game combines arcade gameplay with learning. Players choose a level, race through the track, and solve multiplication questions. Correct answers earn coins, which can be spent in the garage to unlock new cars.

## Main features

- level selection from 1 to 9
- multiplication questions
- obstacle-filled race gameplay
- explanation screen for the rules
- garage with cars and purchases
- coin system
- progress saved in the browser
- localization for Ukrainian, English, and Polish
- sound effects and background music

## Technologies

- React
- TypeScript
- Webpack
- CSS
- HTML5 Audio

## Installation

To install dependencies, use:

```bash
npm install
```

or

```bash
yarn install
```

## Running the project

To run the project locally:

```bash
npm run dev
```

or

```bash
yarn run dev
```

Then open your browser at:

```text
http://localhost:3000
```

## Building the project

For a production build:

```bash
npm run build
```

or

```bash
yarn build
```

## Deployment

To publish to GitHub Pages:

```bash
npm run deploy
```

## How to play

1. Choose a level.
2. Press the "Play" button.
3. Solve multiplication questions during the race.
4. Complete levels and earn coins.
5. Use coins in the garage to unlock new cars.

## Project structure

The project consists of:
- the main menu
- explanation and garage screens
- the race screen
- the localization system
- graphic and sound assets

## Note

The project is easy to extend by adding new levels, cars, sounds, and new types of math challenges.
